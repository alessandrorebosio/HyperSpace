# Tessera

App macOS unica e leggera per:
- remapping della tastiera (stile Karabiner-Elements)
- remapping di pulsanti e scroll del mouse, incluso Logitech (stile LinearMouse)
- tiling window manager (stile AeroSpace)

Obiettivo: un solo processo, nessun driver, un solo permesso (Accessibilità).

Stato: progettazione — vedi [docs/DESIGN.md](docs/DESIGN.md).
